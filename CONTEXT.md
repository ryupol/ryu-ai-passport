# AI Passport

AI Passport is an invitation-only local AI service for a small trusted group. It provides browser chat and personal API access while keeping model inference under the owner's control.

## Language

**Member**:
A person who holds the dedicated `AI Passport` role in the owner's Discord server.
_Avoid_: Subscriber, customer, YouTube member

**Entitlement**:
Current permission to use AI Passport, derived from membership rather than possession of an old credential.
_Avoid_: Subscription

**Chat Access**:
A member's permission to use the browser-based conversational interface.
_Avoid_: Web account

**API Credential**:
A personal, revocable secret that lets one member use AI Passport through compatible software.
_Avoid_: Shared key, master key

**Inference Host**:
The owner-controlled computer that runs models and processes AI requests.
_Avoid_: Cloud AI, VPS

**Operator**:
The owner who invites members, assigns roles, administers credentials, and monitors service health.
_Avoid_: Vendor, provider
